# Security Policy

## Reporting a Vulnerability

Please do not open public issues for vulnerabilities. Report security concerns privately to the repository owner with enough detail to reproduce or evaluate the issue.

Include:

- Affected version or commit
- Steps to reproduce
- Expected and actual impact
- Any relevant logs with secrets removed

## API Tokens

Do not publish your Ship24 token in issues, pull requests, screenshots, logs, or sample data. Parcelite stores the token in macOS Keychain, but Ship24 receives it for API calls.
